# SMPGuide (starter)

Это минимальная заготовка Android-приложения (Jetpack Compose), которая собирает Debug APK в GitHub Actions и отдаёт APK как artifact.

## Как получить APK
1. Открой вкладку **Actions**
2. Запусти workflow **Android Debug APK** (Run workflow) или сделай push
3. Скачай artifact `app-debug-apk`
